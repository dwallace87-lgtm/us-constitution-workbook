# us-constitution-workbook

Two standalone classroom sites:

- [Analyzing the Sale of Manhattan](index.html): the original multilingual source-analysis workbook.
- [Can the New Country Survive?](adventure/index.html): a 53-scene historical decision adventure about the Articles of Confederation and Shays’ Rebellion. Play as a farmer/veteran, Massachusetts state leader, or member of Confederation Congress.

Serve this directory with `python3 -m http.server 8000 --bind 127.0.0.1`. The original workbook is at `/`; the new adventure is at `/adventure/`. No installation or build is required for the adventure.

See [adventure setup and classroom notes](adventure/README.md) for learning objectives, accessibility features, source references, and local save/export behavior.
